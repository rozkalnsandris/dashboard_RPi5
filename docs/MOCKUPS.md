# UI Mockups

These files are **design targets**, not screenshots of a live system. Values shown are illustrative.

The original chat concepts were audited and translated into implementation-friendly SVG references so they can live directly in GitHub, stay sharp at any zoom and remain easy to compare against the HTML/CSS implementation.

## Desktop — v1 audited concept

![Desktop dashboard overview](assets/dashboard-overview-desktop-v1.svg)

Key ideas:

- persistent left navigation;
- health strip at top;
- Needs Attention before secondary widgets;
- Docker table with high-value live metrics;
- Top Consumers;
- recent activity;
- endpoints, backups and deployments below;
- high-density layout without duplicating full Grafana.

## Samsung Galaxy A55 — v1 mobile concept

![A55 mobile dashboard overview](assets/dashboard-overview-mobile-a55-v1.svg)

Key ideas:

- no squeezed desktop sidebar;
- bottom primary navigation;
- Needs Attention first;
- two-column metric cards;
- compact Docker rows;
- recent activity;
- A55-friendly touch targets;
- full mobile page remains readable without horizontal page scroll.
